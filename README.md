# EsponjaRio

Plataforma web colaborativa para mapear pontos críticos de alagamento e áreas verdes na Zona Norte do Rio de Janeiro, com base no conceito de Cidade Esponja.

🔗 **Protótipo:** https://esponjarioprototipo.netlify.app/

> Protótipo acadêmico navegável. Dados, ocorrências e indicadores exibidos são fictícios.

## O problema
Alagamentos são recorrentes na Zona Norte, e a informação sobre onde e quando ocorrem fica dispersa, sem dados que apoiem a decisão do poder público.

## Funcionalidades
- Três perfis de acesso: Cidadão, Técnico/ONG e Gestor Público
- Reporte cidadão pelo celular, com geolocalização
- Validação técnica dos reportes por ONGs e profissionais ambientais
- Painel do gestor com mapa interativo e indicadores (ICVM, taxa de validação, tempo médio de validação)
- Central de alertas para risco de alagamento

## Tecnologias
HTML5 · CSS3 · JavaScript · Leaflet.js · Esri World Street Map · Netlify
